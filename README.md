# Assistente Bancário Conversacional com MCP

## Descrição
Projeto desenvolvido durante o desafio da DIO utilizando MCP, Plaid Sandbox e Lovable.

## Funcionalidades
- Consulta de saldo
- Consulta de extrato
- Consulta de transações
- Consulta de gastos por período
- Histórico de consultas

## Tecnologias
- Lovable
- MCP
- Plaid Sandbox
- GitHub

## Fluxo
1. Usuário envia uma pergunta.
2. MCP consulta os dados bancários.
3. Os dados são retornados ao assistente.
4. O assistente responde em português.

## Exemplos
Pergunta: Qual é meu saldo?

Resposta: Seu saldo disponível é R$ 4.500,00.

- Engenharia de Prompt
- Integração de APIs
